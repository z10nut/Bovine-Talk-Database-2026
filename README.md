# Bovine Talk Database 2026

## Overview
This dataset contains audio recordings of bovine vocalizations collected from the National Research and Development Institute for Cattle Breeding Balotesti and manually annotated based on behavioral contexts. It is designed for training and evaluating machine learning models in bioacoustics, with a focus on identifying animal welfare and stress states.

## Dataset Structure
The repository utilizes Git Large File System to store `.wav` files and is organized according to the processing stage:

* `raw_recordings/`: Unaltered, raw source audio files captured directly by the recording equipment.
* `manual_cropped/`: Manually isolated audio segments containing clear cow vocalizations, ready for feature extraction and model training.

Both directories are subdivided into the following four context categories:
* `Positive`
* `Mild_Negative`
* `Moderate_Negative`
* `Severe_Negative`

## Data Collection

The dataset was compiled using two types of audio recording equipment: custom IoT devices developed at the National University of Science and Technology Politehnica Bucharest (UPB) and microphones provided by the Research and Development Institute for Cattle Breeding (ICDCB). In scenarios where both systems operated simultaneously, there may be duplicate instances of the same vocalization captured from different acoustic angles.

Recordings are categorized based on the following monitored behavioral scenarios:

* **Severe_Negative**
  * **Subjects:** 2 adult cows and 3 calves.
  * **Context:** Acute stress generated by cow-calf separation.
  * **Timeframe:** Continuous monitoring over an approximately 24-hour period.
  * **Equipment:** UPB Devices and ICDCB Microphone.

* **Moderate_Negative**
  * **Subjects:** 2 adult cows.
  * **Context:** Isolation in the shelter following morning milking.
  * **Timeframe:** Approximately 5 hours per animal, starting around 07:45.
  * **Equipment:** UPB Devices.

* **Mild_Negative**
  * **Subjects:** 5 calves in individual hutches.
  * **Context:** Anticipation of feeding followed by frustration.
  * **Timeframe:** Recording starts around 15:00 (anticipation phase) and captures the subsequent frustration period caused by delayed milk administration, beginning around 16:30.
  * **Equipment:** UPB Devices.

* **Positive**
  * **Subjects:** 3 calves in individual hutches.
  * **Context:** Anticipation of feeding.
  * **Timeframe:** From approximately 14:00 up to the moment of milk administration.
  * **Equipment:** UPB Devices and ICDCB Microphone.

## Usage & Downloading
Because this repository contains large audio files, Git LFS is strictly required to download the actual `.wav` raw files instead of their text pointers.

```bash
# 1. Install Git LFS
git lfs install

# 2. Clone the repository
git clone git@github.com:z10nut/Bovine-Talk-Database-2026.git

# 3. Pull the actual audio files
cd Bovine-Talk-Database-2026
git lfs pull
